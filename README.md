# Himada — Presentation Website

> Адаптивная интерактивная презентация проекта [Himada](https://github.com/Fastop06/himada) для широкой аудитории.

## 🌐 Live Demo
👉 **[https://fastop06.github.io/himada-presentation/](https://fastop06.github.io/himada-presentation/)**

---

## ⚡ Особенности
- **Без кнопок и лишнего визуального шума**: чистый минималистичный дизайн в стиле Apple Keynote / Linear.
- **Полноэкранный режим**: двойное нажатие клавиши `Cmd` (⌘) или `Ctrl` переводит браузер в полноэкранный режим.
- **Понятно без технического бэкграунда**: простые аналогии, наглядные схемы «Было / Стало» и живые графики ускорения.
- **Рассчитано на 5-минутный питч**: 6 сфокусированных слайдов с выверенным таймингом.

---

## 🎮 Управление
- **Дважды `Cmd` (⌘)**: переключение полноэкранного режима
- **`Пробел` / `→` / `↓`**: следующий слайд
- **`←` / `↑` / `Backspace`**: предыдущий слайд
- **Колесико мыши**: плавный переход между слайдами
- **Клик в правой части (75%)**: следующий слайд
- **Клик в левой части (25%)**: предыдущий слайд
- **Свайп на тачпадах / смартфонах**: влево / вправо
